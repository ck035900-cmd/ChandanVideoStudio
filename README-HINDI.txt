Chandan Video Studio - Android APK Build Project

इस प्रोजेक्ट में WebView आधारित Android ऐप और GitHub Actions APK build workflow है।

APK बनाने के लिए:
1. इस ZIP को extract करें।
2. पूरे प्रोजेक्ट की फाइलें GitHub repository की main branch में upload करें (folder structure सहित)।
3. GitHub में Actions tab खोलें।
4. “Build Chandan Video Studio APK” workflow चुनें और Run workflow दबाएँ।
5. Build सफल होने पर workflow run के Artifacts भाग से ChandanVideoStudio-debug-apk डाउनलोड करें।

ध्यान दें: यह MVP है। Trim, preview, aspect ratio, text overlay, basic filters, speed, optional audio और browser-supported export मौजूद हैं। Export format फोन/browser के समर्थन पर निर्भर है; यह पूर्ण native multi-track editor नहीं है।
